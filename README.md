# Task Manager API 📝

A simple Spring Boot REST API to manage tasks. This project demonstrates basic CRUD operations using Java, Spring Boot, and an in-memory H2 database.

---

## 🚀 Features

- Create new tasks
- Get list of all tasks
- Update an existing task
- Delete a task
- Basic RESTful structure
- Uses H2 in-memory DB for demo

---

## 🛠️ Tech Stack

- Java 17
- Spring Boot 3.x
- Spring Web
- H2 Database
- Maven
